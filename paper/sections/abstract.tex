\begin{abstract}
Reasoning models in the o1 and DeepSeek-R1 mold apply reinforcement learning
to a language model's own weights so that it emits a better chain of thought,
token by token. We study the complementary design point: the language model is
\emph{frozen}, and reinforcement learning trains a small \emph{external}
controller (a few million parameters: a verb head, a pointer head, and a Q
head) that orchestrates it. The controller's actions are typed pairs
$(\textit{verb}, \textit{target})$ applied to a structured, nested reasoning
forest of goals, hypotheses, and verified facts; each action is a
\emph{lens} that renders only a grounded-local slice of the state into the
frozen model's context and writes the output back locally. A symbolic
verifier is the sole reward source: no reward model, no learned process
reward, no LLM judge. The controller is trained by off-policy value-based
Q-learning with Monte Carlo returns from the verifier terminal, warm-started
by behavior cloning from an LLM-as-controller teacher; Monte Carlo Tree
Search enters only as an optional, strictly additive accelerator and a
test-time compute knob. We pre-register a compute-versus-accuracy evaluation
on verifiable math benchmarks against FLOP-matched sampling and
orchestration baselines. \stub{headline empirical result, pending runs}
\end{abstract}
