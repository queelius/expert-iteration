# Archived experiments

These data and results predate the 2026-06 action-space redesign (the move to the
`(verb, target)` lens model and the reduced verb set). They reflect the older
verb-only / seven-verb pilot and are kept for the record only. Do not treat any
number here as current: the paper no longer leans on them. New runs against the
redesigned action space will live under `experiments/`, not here.

- `data/`    : pilot distillation data, trained heads, and budget-sweep / eval outputs.
- `results/` : pilot run summaries and the correctness audit.
