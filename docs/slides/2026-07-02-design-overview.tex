% ---------------------------------------------------------------- overview
\begin{frame}{What this is (and is not)}
  \begin{block}{The system}
    A \alert{tiny external controller} (verb head + pointer head + $Q$ head,
    a few million parameters) learns to orchestrate a \alert{frozen} large
    language model (LLM) by issuing typed $(\text{verb}, \text{target})$
    actions over a structured, nested reasoning forest. A \alert{symbolic
    verifier} is the only reward source.
  \end{block}
  \begin{itemize}
    \item \textbf{Not} o1 / DeepSeek-R1: reinforcement learning never
          touches the LLM's weights
    \item \textbf{Not} a learned reward model: no process or outcome reward
          model, no critic, no LLM-as-judge anywhere in the reward path
    \item Training spine: off-policy value-based $Q$-learning; Monte Carlo
          Tree Search (MCTS) is a strictly additive accelerator and the
          test-time compute knob
  \end{itemize}
\end{frame}

                   fill=gray!20, text=gray},
      edge from parent/.style={draw, -{Stealth[length=1.5mm]}}]
    \node[g] {Goal: solve $|x-2| = 5$ \; \scriptsize(connective: exhaustive\_case)}
      child {node[g] {Case $x \ge 2$:\\ $x - 2 = 5$}
        child {node[f] {Fact: $5 + 2 = 7$ \;(verified)}}
      }
      child {node[g] {Case $x < 2$:\\ $2 - x = 5$}
        child {node[f] {Fact: $2 - 5 = -3$ \;(verified)}}
        child {node[dead] {Hyp: $x = 3$\\ (abandoned)}}
      };
  \end{tikzpicture}

  \medskip
  \begin{itemize}
    \item Frozen dataclasses: \texttt{Goal}, \texttt{Hypothesis},
          \texttt{Fact}, \texttt{VerifierCall}; verbs are total functions
          $\text{Graph} \to \text{Ok} \mid \text{Err}$
    \item No reward or value stored in nodes; \texttt{solved}/\texttt{verified}
          are derived predicates
    \item Structure never gates: the connective is metadata for the
          controller, not a hard rule
    \item Closed subtrees compact to one line in every rendered view
          (built-in roll-back / summarize)
  \end{itemize}
\end{frame}

% ---------------------------------------------------------------- actions
\begin{frame}{Action space: six verbs, one pointer}
  \begin{center}
    \footnotesize
    \begin{tabular}{lll}
      \toprule
      Verb & LLM call? & Effect \\
      \midrule
      \verbword{split} & yes & decompose a goal into subgoals or exhaustive cases \\
      \verbword{form\_hypothesis} & yes & add a tentative claim under a goal \\
      \verbword{compute} & yes & add one checkable ground equation as a fact \\
      \verbword{verify} & \alert{no} & run the symbolic checker on a node's statement \\
      \verbword{commit} & \alert{no} & close a goal on verifier-vouched evidence \\
      \verbword{abandon} & \alert{no} & prune a dead end (excluded from menus and views) \\
      \bottomrule
    \end{tabular}
  \end{center}
  \begin{block}{The lens property}
    Choosing $(\text{verb}, \text{target})$ simultaneously picks the
    operation \emph{and} the slice of state the frozen generator sees:
    problem + ancestor path + target subtree, siblings hidden, closed
    subtrees compacted. Write-back is local and sanitized against marker
    injection.
  \end{block}
\end{frame}

% ---------------------------------------------------------------- reward + training
\begin{frame}{Reward invariant and the training ladder}
  \begin{columns}[T]
    \begin{column}{0.48\textwidth}
      \textbf{Reward (load-bearing)}
      \begin{itemize}
        \item Terminal $+1/-1$ at root \verbword{commit}; $0$ elsewhere
        \item Masked/illegal action: small penalty
        \item No learned reward of any kind, ever
        \item Aesthetic signals may enter only as search priors, never as
              Bellman targets
      \end{itemize}
    \end{column}
    \begin{column}{0.48\textwidth}
      \textbf{Three rungs}
      \begin{enumerate}
        \item \alert{LLM-as-controller}: a strong teacher picks
              $(\text{verb},\text{target})$; trajectories logged as
              JSON lines
        \item Behavior cloning: warm-start $\pitheta$ on rung-1 data
        \item $Q$-learning fine-tune: off-policy, n-step / Monte Carlo
              returns from the verifier; MCTS optional for better targets
      \end{enumerate}
    \end{column}
  \end{columns}
  \medskip
  \footnotesize
  Design-true collection regime: a strong \emph{hosted} teacher model
  (reached over a network endpoint) decides; a \emph{local small generator}
  writes all content, so trajectories reflect the deployed model's state
  distribution.
\end{frame}

% ---------------------------------------------------------------- prior art 2
\begin{frame}{Prior art: the three real threats, and what survives}
  \textbf{Threats a reviewer will raise}
  \begin{enumerate}
    \item TS-LLM read as ``same loop, different reward source''
    \item ArCHer (value RL that trains the LLM itself) + GSoS +
          verifiable-reward RL: ``each ingredient is published, the
          combination is engineering''
    \item Active Context Curation as concurrent work on the lens axis
  \end{enumerate}
  \smallskip
  \textbf{What survives: the conjunction, claimed as such}
  \begin{itemize}
    \item Tiny \emph{external} controller (neither the LLM nor an LLM-sized critic)
    \item Factored verb + pointer heads over live node ids of a growing forest
    \item Off-policy value-based $Q$-learning as the spine, MCTS strictly additive
    \item Symbolic verifier as the sole reward, no learned value or reward
          model anywhere
    \item The lens property: action selection = context scoping, with local write-back
  \end{itemize}
  \smallskip
  \footnotesize Honest caveat: defensible but thin per-element; claim the
  conjunction, not a new RL algorithm.
\end{frame}

\begin{frame}{Casework: the structural action space fires}
  \textbf{The dataset does its job} (\texttt{casework-v1}: 300
  SymPy-verified problems with provenance): on a linear benchmark the
  chain policy is optimal, so structural verbs never fire; on casework
  they reach \alert{12--23\%} of decisions, with \verbword{split} in
  20/20 probe episodes and \verbword{abandon} on the dead-case families.
  \medskip

  \textbf{The teacher-LLM controller plateaus at 20--25\%.} A win needs
  roughly 10 correct sequential decisions and per-step protocol fidelity
  binds; prompt engineering, a $5\times$-price teacher, longer
  completions, and coarser verified steps all measured null against
  pre-registered readings.
  \begin{block}{Why a trained controller can do better}
    The teacher's dominant errors are illegal action choices and
    repetition, errors a pointer head restricted to the legal menu cannot
    make by construction; and its logged decisions, right and wrong, are
    exactly the behavior-cloning data Phase B trains on.
  \end{block}
\end{frame}

\begin{frame}{The measured difficulty ladder, and the target}
  \begin{center}
    \footnotesize
    \begin{tabular}{@{}lcc@{}}
      \toprule
      Direct prompt, same scoring & Qwen2.5-1.5B (deployment) & gpt-4.1-mini \\
      \midrule
      quadratics (f3) & 75\% & 100\% \\
      absolute value (f1a/f1b) & 40 / 35\% & 100\% \\
      piecewise (f2a/f2b) & 31 / 15\% & 100\% \\
      casework-v1 as shipped (the five above, 240) & \alert{39.2\%} & 100\% \\
      \midrule
      held-out: word problems (f7) / counting (f8) & 5\% / 5\% & 98\% / 100\% \\
      \bottomrule
    \end{tabular}
  \end{center}
  \smallskip
  One generator spans 5--75\% on the deployment model while staying
  trivial for the mini tier (harder mixes are a \emph{weighting}
  exercise); dead-case problems are the small model's weak axis (33\% vs
  43\%), exactly what \verbword{abandon} targets.
  \begin{block}{The decisive comparison, now concrete}
    Qwen2.5-1.5B + trained controller must beat \alert{39.2\%} on
    casework-v1. Every teacher-side alternative (prompts, a
    $5\times$-price teacher, completion budget, solve-claim steps)
    measured null; the trained controller is the remaining lever.
  \end{block}
\end{frame}

% ---------------------------------------------------------------- next steps
\begin{frame}{Next steps}
  \begin{enumerate}
    \item \textbf{Design-true collection}: hosted teacher decides,
          \emph{local} Qwen-1.5B writes content. First probe 0/20: strict
          payload schemas mask 55--63\% of the small model's typed-verb
          output; lenient coercion at that boundary is in progress
    \item \textbf{Phase B}: per-node encoder + pointer head,
          behavior-cloning warm-start on rung-1 trajectories, then
          $Q$-learning fine-tune against the verifier
    \item \textbf{The decisive comparison}: Qwen-1.5B + trained controller
          vs the same model prompted directly; the target is
          \alert{39.2\%} on casework-v1, and the approach succeeds or
          fails on that margin
    \item \textbf{Standard benchmarks later}: GSM8K/MATH follow once the
          casework loop shows progress
  \end{enumerate}
  \medskip
  \begin{block}{One-sentence summary}
    Search and scale live in the teacher and the compute knob; what we
    \emph{learn} is a tiny verifier-anchored controller over a frozen LLM.
  \end{block}
\end{frame}
